# SHAE — Documentación en Español

## Instalación
Ejecute `scripts/install.sh` para instalar el procesador de datos en F#.

## Plataforma
Herramienta de línea de comandos (CLI) en lenguaje F# (.NET).

## Build
`dotnet build -c Release`

## Release
GitHub Release v0.1.0 disponible.

## Diseño
Sigue el SHAE Field Manual: papel cálido #F2EEE5, tinta #191712, óxido #B3341B, 0px de radio, bordes de 1px.
