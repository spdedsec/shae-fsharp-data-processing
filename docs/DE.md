# SHAE — Deutsche Dokumentation

## Installation
Führe `scripts/install.sh` aus, um das F#-Datenverarbeitungstool zu installieren.

## Plattform
CLI-Tool (F#-Sprache, .NET).

## Build
`dotnet build -c Release`

## Release
GitHub Release v0.1.0 verfügbar.

## Design
Folgt dem SHAE Field Manual: warm paper #F2EEE5, ink #191712, oxide #B3341B, 0px Radius, 1px Rahmen.
